# Movie Tagging Service. План проекта

Обучение модели для генерации тегов (меток) к фильмам на основе описаний и жанров.

В качестве дипломной работы бакалавра разработано веб-приложение с рекомендательной системой фильмов и семантическим поиском. Данный проект - отдельный API-сервис, который взаимодействует с основным приложением и генерирует теги к фильмам.

**Применение тегов:**
- отображение на странице с детальной информацией о фильме
- формирование тематических подборок на главной странице

---

## Этап 1. Подготовка данных

### 1.1. Загрузка данных

- локальная база данных содержит 797 фильмов
- структура файла .csv: `id`, `movie_name`, `year`, `rating`, `runtime`, `meta_score`, `age_rating`, `overview`, `genres`, `directors`, `countries`

Файл: `notebooks\eda_data_preprocessing.ipynb`

### 1.2. Генерация тегов через LLM

- используется локальная модель Qwen2.5-7B-Instruct-1M-GGUF
- промпт был оптимизирован: генерируются обобщенные теги, исключаются жанры и года
- результат: 744 фильма с тегами, 50 целевых тегов

Файл: `notebooks\generating_tags.ipynb`

### 1.3. Очистка тегов

- исключены жанры, года, страны
- объединены дубликаты

Файл: `notebooks\tag_analysis_and_preparation.ipynb`

### 1.4. Подготовка данных для обучения

- создание бинарной матрицы (фильмы x теги)
- разделение на train/val/test
- сохранение в pickle

Файл: `notebooks\tag_analysis_and_preparation.ipynb`
